☄️ Chuva de Meteoros

Um jogo 2D desenvolvido em Python utilizando a biblioteca Pygame, como projeto para a disciplina de Linguagem de Programação Aplicada, da Uninter.

🎮 Sobre o jogo

O objetivo é controlar uma nave espacial, destruir os meteoros que aparecem na tela e sobreviver aos desafios.

Objetivo principal: destruir 20 meteoros sem perder todas as 3 vidas disponíveis!

🕹️ Controles
Tecla	Ação
⬆️ ⬇️ ⬅️ ➡️	Movimentar a nave
W A S D	Movimentar a nave
Espaço	Atirar
Enter	Iniciar o jogo / Voltar ao menu
⚙️ Tecnologias utilizadas
Python 3.12+
Pygame – biblioteca utilizada para desenvolvimento do jogo.
🚀 Como executar o projeto
1. Pré-requisitos

Certifique-se de ter o Python 3.12 ou superior instalado em sua máquina.

2. Instale o Pygame

Abra o terminal na pasta do projeto e execute:

python -m pip install pygame

3. Execute o jogo

Após instalar as dependências, execute:

python main.py

🎯 Objetivo do projeto

Este projeto foi desenvolvido com o intuito de aplicar na prática os conceitos estudados na disciplina de Linguagem de Programação Aplicada, explorando recursos da linguagem Python e da biblioteca Pygame na criação de um jogo 2D.

Desenvolvido como projeto acadêmico para a Uninter. 🚀
